# Group Calculator

A scientific calculator application developed collaboratively in Java. The project uses Java Swing to provide a graphical user interface for performing basic arithmetic operations and a variety of scientific calculations.

## Features

### Basic Arithmetic

* Addition, subtraction, multiplication, and division
* Percentage calculations
* Positive and negative number toggling

### Scientific Functions

* Squares and cubes
* Exponentiation and roots
* Factorial calculations
* Trigonometric functions: sine, cosine, and tangent
* Hyperbolic functions: sinh, cosh, and tanh
* Natural logarithm (ln) and base-10 logarithm (log)
* Exponential functions: \(e^x\) and \(10^x\)
* Reciprocal calculations
* Mathematical constants: π and e
* Scientific notation support

### Graphical User Interface

* Java Swing-based interface
* Button-based input
* Dark theme with purple buttons
* Clear and delete controls
* Basic error handling

## Technologies Used

* **Java** — application logic and calculations
* **Java Swing and AWT** — graphical interface and event handling
* **Object-Oriented Programming** — abstraction, inheritance, and polymorphism

## Getting Started

### Prerequisites

* Java Development Kit (JDK)
* IntelliJ IDEA or another Java-compatible development environment

### Running the Project

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the `GroupCalculator` folder in IntelliJ IDEA.

3. Allow the IDE to load the project configuration.

4. Locate `Main.java` in the `src` directory and run it if it contains the application's entry point. Alternatively, run `ScientificCalculator.java` if that is where the `main` method is defined.
